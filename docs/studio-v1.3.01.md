# v1.3.01：布局与人物轮廓修复

版本 1.3.01 / 10301。此版本依据用户提供的导航错位和人物边缘截图修复，不以构建成功代替画面检查。

## 界面

- 底部导航每个按钮内水平、垂直居中，使用主题 onPrimary 文字色及至少 48dp 点击高度；不再把文字放在整块选中胶囊的左侧。
- “已生成”缩略图状态改为小型高对比勾选角标；其他状态使用深底浅字的小标签，避免绿色大字覆盖人物。无障碍状态说明保留。
- Gallery/设置采用包含 systemBarsIgnoringVisibility 的安全留位，避免沉浸 Viewer 返回后，瞬时系统栏覆盖标题或底栏。Viewer 的双眼手势与播放器算法不改。
- 滚动条只在滚动/拖动及结束后一秒出现，减细并跟随主题，避免常驻灰线贯穿标题和图片。
- 生成版本封面采用 4:3，标题使用更紧凑字号。长参数说明默认最多三行，发生截断时可打开完整、可滚动的说明弹窗；避免大字体下参数被整页说明淹没。

## 上游核对与修复依据

核对当前上游 main `30372fec69a1929ce6eb5fded8d23ba2604fd68f` 的 [外部深度 V2.2 节点](https://github.com/SamSeenX/ComfyUI_SSStereoscope/blob/30372fec69a1929ce6eb5fded8d23ba2604fd68f/sbs_v2_with_external_depth.py) 及 [自动深度处理](https://github.com/SamSeenX/ComfyUI_SSStereoscope/blob/30372fec69a1929ce6eb5fded8d23ba2604fd68f/depth_estimator.py)。

| 项目 | 实际代码/测试设置 |
| --- | --- |
| External 默认强度 | 5，位移约为眼图宽度 1% |
| 补洞 | Telea，半径 3px，Fast/HighSodium 开启 |
| 默认眼序 | 上游默认 Cross-eyed；本 App 按用途明确采用 Parallel，左眼原图、右眼投影 |
| blur_radius | External 参数默认 3，但其函数没有使用此参数；不能把它当作已经做过平滑 |
| 自动深度 | 上游自动流程先恢复图像尺寸并做 Gaussian 平滑；与直接传入低分辨率外部深度不同 |

上一版 V8 将 518×518 深度直接量化并最近邻取样到眼图，台阶会被放大。含手机原有 1024 深度放大设置时，还确认 Pillow 最近邻与原中心取样公式在 1024→1536 的边界选择不同，测试斜率中 303 列不同。不是增大强度或盲目套用官网旧示例中的 50 就能解决。

修正模式 `REFERENCE_V9 / depthSSS22V9` 在最终投影前，将已有浮点深度双线性恢复到实际眼图大小，Gaussian 3×3 后才量化，之后仍采用所核对的 V2.2 投影及 Telea。它是本 App 的移动端预处理修正，不冒充上游发布了“V9”，也不声称整条 ComfyUI 自动推理逐像素相同。

V6/V7 与旧 V8 算法、缓存保留。仅原参考模式的当前设置从 V8 转到 V9，强度和其余偏好不重置；既有视频队列按原记录继续使用 V8，独立解码规则不迁移旧任务。已有结果不会自动重做，需要在修正模式下重新生成；列表将旧参考结果标为 1.3.00。

原模型仍为 518×518，GPU delegate 的线程归属和强制 GPU 不改。可选深度放大的参数、顺序和 `_du1_...` 标识保留；参考修正的最终网格恢复是单独的投影阶段。额外原生缓冲计入该模式自身预算，Mat 在 finally 释放，补洞分配仍串行受限。

## 画面与设备证据

- 官方素材来自作者 README 的 [公开工作流截图](https://github.com/SamSeenX/ComfyUI_SSStereoscope/assets/8541558/6b972838-07ca-4e64-a3a4-32277ddcf4c7)。没有找到该摄影原图下载，因此明确使用其输入预览裁片，560×836；不称它为原始高清图，也不将它加入公共仓库或 APK。截图展示的旧节点参数不代表当前 External 默认值。
- 官方裁片及用户先前指定三张人像在手机、平板分别用强制 GPU 获取浮点深度，并在相同输入/相同深度/相同强度 5 下运行旧、新两条路径。另保留设备原有可选深度放大设置，特别覆盖手机的 1024、双三次、先放大后处理。
- 用未修改的上游 External 函数执行对照；仅用 NumPy 适配张量传输及进度接口，没有更换其投影/补洞代码。修正路径与上游接收同一份预处理深度后的输出核对。旧 V8 的放大边界差异单独记录，没有用放宽断言掩盖。
- 手臂、腰部、头发和摩托车后视镜边缘均保留前后局部图并实际查看。三张人像中，台阶及散点减少，以第三张手臂最明显；摩托车样例变化较小。腰侧及其他遮挡区域仍有模糊/拉丝，不能宣称完全修复或所有素材更优。没有对原图或整幅成品做模糊处理来掩盖边缘。
- 私人原图、深度、PNG 对照和截图保存在 `.local/iteration-1.3.01/`。QA 推理直接读写 App 专属目录，不经过 MediaStore/图库预加载。UI 测试前保存并隔离原队列，结束后恢复，避免重复上一轮范围外生成。
