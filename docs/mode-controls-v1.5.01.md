# v1.5.01：固定默认值、单一反转与精简对比

本版纠正 v1.5.00 的交互理解：用户希望参照 V10 强度 50 的实际视差试调其他模式，再保存固定、可编辑的默认值。移除新设置中的逐图自动跨度换算；历史队列/结果仍按原快照处理。

## 固定数值如何试调

使用已授权的三张人像与作者 README 示例裁片，复用既有 518 深度，调用 Android 实际六条投影路径，固定单眼宽 1280 和窗口 3，逐档渲染共 104 个候选。V10 固定 50；V6 试 80/90/100/110/120，V7 试 35/40/45/50/55，V8/V9 试 2.5/3/3.5/4/4.5，V11 试 40/45/50/55/60。没有新建图库任务或重新推理这批深度。

对实际生成的眼图匹配源图特征，采用前后向一致性排除明显遮挡/误匹配，比较相对远背景的水平位移，并检查人物轮廓局部图。各样例误差等权平均；本轮候选中选择 V6 **100**、V7 **45**、V8/V9 **3.5**、V10/V11 **50**。对应相对位移平均误差约 0.50、0.44、1.15、1.11、0、0.33 像素。

这比只比较深度图 P90−P10 更接近实际投影，但仍不是人的双眼主观舒适度结论，也没有穷举全部连续参数。不同路线的静态眼、会聚、遮挡和纹理填充仍不同。固定值是试调起点，用户可直接输入小数、切换模式独立保存，以及保存个人默认。

强度仍是各路线原生单位；External 的几与主节点的几十不直接等价。上述匹配条件是单眼宽 1280；现有算法的位移与输出宽度关系不同，不能承诺所有输出尺寸都保持相同主观深度。本版不为此悄悄改写历史投影算法。

旧的自动档转为对应固定数值，保留滤波、反转、输出等其余设置。明确自定值保持原值。旧队列的 `_eq1050` 快照与历史缓存保持兼容，不把旧任务改成新的默认值。

## 反转与对比

参数页只提供一个“反转深度”：黑白互换，并改变前后关系。历史的模型极性和投影眼序字段仍用于读取旧设置/队列，UI 合并其有效状态；用户调整后由模式内部约定处理眼序，不再要求用户理解两个反转开关。新生成的调试深度图按两个历史字段合并后的方向显示；不改写既有诊断文件或旧任务。

进入六模式对比即捕获各模式当前参数生成。界面只有一个显示当前模式的循环切换按钮，去掉尺寸档位、默认/已存参数重生成和多排模式选择。预解码结果仍共用同一手势会话，切换无图片动画，保留缩放与位置。各模式输出上限在共同内存约束内生效。

## 真正的模型输入分辨率实验

电脑使用同一个本地 Depth Anything V2 Small HF 模型，在实际输入张量 266×266、518×518、1036×1036 下分别推理四份指定素材，共 12 组；各素材 RGB 与 V10/50 投影参数固定。原始输出深度及成品均保留。1036 会改变局部结构，不能仅凭更细或更大的图断言整体更好。

Android 保留模型的真实输入声明为 `[1,518,518,3]`，没有动态 shape signature。平板独立 GPU 会话实际测试：518 分配及推理成功；770、1036 均在分配阶段因节点 3 `RESHAPE` 的元素数量不匹配失败（1161600/2102784 对 525696）。没有 CPU fallback，也没有替换稳定模型。要在 App 使用更高模型输入，需要另外导出并验证对应模型，当前未提供一个无效的输入分辨率选项。

电脑 PyTorch 模型的成功不等同于 Android TFLite 包可运行。深度放大只做预测后的插值；输出长边只影响 RGB 解码/输出。二者都不冒充模型输入分辨率。私人图像和实验报告位于 `.local/iteration-1.5.01/`，不上传。

## 验收

平板真实界面已通过：长文件名与长按调试、单按钮连续六次切回 V10、精确缩放/位移和返回画面哈希、跨中线/持续拖动、旋转及返回桌面。手机未参与本版测试。最终构建、设置和发布记录见发布验收；不能用 v1.5.00 结果代替本轮证据。

## V8/V9 反转专项检查

同一四份样例、同一深度和 1280 单眼宽，V8/V9 强度 3.5 分别生成默认及额外反转的眼图。默认与 V10/50 的相对背景视差平均差为 1.15 / 1.11 像素；额外反转后为 8.21 / 8.18 像素，四份样例的前景相对视差符号均反转。P3 的前景值约从 +6.98 变为 −6.98，而 V10 为 +6.00。

检查局部图可见反转改变空洞出现侧，但仍保留轮廓伪影；不能据此把 V8/V9 全局反转。V8 的量化与 V9 的浮点恢复/平滑，以及共同的 Telea 补洞与静态眼约定仍与 V10 不同。本版没有声称修复这些路线的所有边缘问题。实图证据 `direction-evidence.json` 与四张方向对照图在私密验收目录。
