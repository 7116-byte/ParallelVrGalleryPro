- 模型已就绪的新图片小样本约快 4–13%；首图包含模型初始化仍约 4.5–4.8 秒，未证明明显提升。GPU 算子仍约 243 ms；不将 CPU 打包/读取改善写成 GPU 算子加速。
- 本轮未重复手机、完整触控/旋转、长视频或旧版 App 内下载覆盖升级端到端流程。任意缓存缺口的历史平滑状态、原生库 16 KB 对齐等旧限制保留。
