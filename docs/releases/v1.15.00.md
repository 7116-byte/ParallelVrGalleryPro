# v1.15.00 · 视频分段编码与图库优化

本版源码版本为 `1.15.00 / 11500`，沿用 Pro 包名 `com.local.parallelvrgallerypro`。正式安装包沿用原发布证书。GitHub 固定资产名为 `app-debug.apk` 和 `app-debug.apk.sha256`，供已发行版本识别更新。

## 视频生成

- 无旧逐帧缓存的新任务分段编码 AVC。每段通常约 1.5 秒，最多 72 帧。每次只提交完整分段，用最近一段的时序深度状态继续生成。中断后从首个尚未完成的分段续跑。
- 合并时按源时间轴写入各段的压缩视频样本，并复制原音频，形成一个 SBS MP4。完成并登记成品后清理本版本的分段与临时帧。已有逐帧缓存的未完成任务沿兼容路径续跑。
- 双竖版的横屏视频可把旋转缩放和浮点深度转回交给两个独立 CPU 工位，GPU 推理仍使用一个拥有者线程。各工位的等待队列容量为 4，同时受总体内存限制。时序平滑和编码保持原帧序。

## 模型与图库

- 图片和视频分别选择 QNN FP16 或 FP16 + 末端 FP32，以及 518–1036 的名义边长。输入比例可选固定方形、14 像素分块或双竖版。双竖版 1036 档使用 756×1344 和 882×1176，横向素材先转为竖向输入，再把浮点深度转回。
- 图片结果按完整生成参数归入相册。使用新参数生成前可查看目标参数，已有同参成品或任务的原图会跳过。重新生成成功后只替换本次选定的旧结果。
- 全部、相册、生成和各自详情恢复独立的滚动锚点。浮动标题在深浅主题中使用对比阴影。生成页图片／视频切换条与网格重叠时，外槽透明度 75%，选中项透明度 50%，文字保持不透明。回到没有网格覆盖的位置后恢复实色。

## 已有验证

同版本较早的本地 Release 构建通过 237 项 JVM 测试，Lint 0 错误。最终构建、GitHub CI 与公开资产验收按各自结果核对。

平板用 720p 合成短片检查从空缓存生成和分段合并。10 帧按 6＋4 分段，输出 2560×720 的单源 SBS，逐帧检查顺序通过。视频 PTS 相对原片的最大误差约 0.67 微秒。119 个 AAC 包与其时间戳一致。成片登记后无分段或帧缓存残留。该样本未中途暂停，进程被终止后的恢复、长视频及其他设备的编码器表现仍需分别验收。

平板还检查了切换条在列表顶部、滚动覆盖网格、回到顶部这三个状态。设备侧测试范围与构建检验独立。性能随模型、输入张量、素材和设备变化，此短片结果只覆盖上述样本。
