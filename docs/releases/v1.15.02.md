# v1.15.02 · 视频多选操作

进入「生成 → 视频」，长按一项打开多选操作栏。「全部开始」「全部暂停」按当前视频任务列表计算数量，分别执行符合条件的任务。「开始所选」「暂停所选」只处理已选视频。开始操作会使用任务已保存的参数和分段继续生成。

## 视频深度诊断

视频工作长边从 v1.15.01 起按任务固定，已有分段据记录恢复。v1.15.00 的正式包仍逐帧检查内存，使用 V10 或 V11 时可导致后处理尺寸随帧变化。在「设置 → 通用 → 应用更新」可查看实际安装的版本。[v1.15.01 同素材尺寸与耗时对照](v1.15.01.md)
