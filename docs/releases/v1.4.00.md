# ParallelVrGallery Pro v1.4.00

新增与实际 ComfyUI 主节点对应的生成模式，并增加亚像素轮廓处理。版本 1.4.00 / 10400。

- “原样兼容”沿用主节点 Legacy 的眼序、强度、覆盖及填充规则；同一份手机深度的 40 / 60 八组对照与 PC 输出逐像素一致。
- “亚像素”保留浮点位移并按深度、覆盖率处理边缘，减少指定人像的台阶。没有对原图或整幅成品做模糊；复杂遮挡仍可能异常，投影计算也更慢。
- 设置 → 深度与输出，可选择两个新模式，使用“60 / 3 / 反转”预设作对照。预设同时关闭额外深度放大，保留 GPU、输出尺寸及其他设置。已有结果需要明确重新生成才能使用新模式，旧版本结果和队列不变。

四个指定样例已在手机真实强制 GPU 上生成，并与 PC 真实 Small 模型及主节点比较。实际图片入口与直接 renderer 一致；两个模式各完成三帧合成视频的时间平滑路径检查。手机正常/大字体、深浅及横屏参数界面已检查。私人素材和验收截图不上传。

原包名、原发布证书及覆盖升级规则保留。正式资产继续使用 `app-debug.apk` 和 `app-debug.apk.sha256`，实际为不可调试的 Release 构建。

技术依据、具体测试范围及性能代价见 [技术记录](https://github.com/7116-byte/ParallelVrGalleryPro/blob/main/docs/comfy-main-v1.4.00.md)。16 KB 支持、长视频压力及主观佩戴效果仍未完成。
