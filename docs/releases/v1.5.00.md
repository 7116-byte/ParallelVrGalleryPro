# ParallelVrGallery Pro v1.5.00

版本 **1.5.00 / 10500**。六种模式分别保存视觉参数，支持“保存为默认值”、恢复个人默认及恢复内置默认。内置默认按每张图片实际尺寸和深度跨度匹配 V10 深度 50，升级保留原来的自定设置。

长按 Viewer 文件名或点击“调试”，可临时生成当前图的六种模式，无图片切换动画，并保持双眼缩放、位置。模型深度和投影深度分别展示、分别控制反转。长文件名省略，按钮保持单行。

“重新生成”成功后只替换当前查看/选中的图片结果，失败保留旧结果；“使用新参数生成”另存一份。原图及其他历史保留。图片发布事务支持启动恢复；来源队列、GenerationGuard、强制 GPU、旧算法与旧缓存保持兼容。
