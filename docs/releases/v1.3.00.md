# ParallelVrGallery Pro v1.3.00

统一创作工具界面，并新增参考 SSS 外部深度 V2.2 的独立投影模式。版本为 1.3.00 / 10300。

- 全部、相册、生成、Viewer、设置、任务和提示统一深浅主题，跟随系统。标题自然滚动，底部操作槽避让内容，适配手机、平板、横竖屏与大字体。
- 参数分组及作用说明更清楚；视频任务显示文件名、帧数、进度与错误。修复生成网格长按松手后取消选择，视频整张卡片可点击。
- 新增“参考新版 v2.2”：按图宽投影、显式空洞掩码与 Telea 修补。建议强度从 5 开始；保留 V6/V7 原算法、原缓存及深度放大设置，不自动替换旧结果。
- 保留来源队列、当前图片优先、前后预加载、暂停原因、删除 token、强制 GPU、GPU 线程归属及单源 SBS 视频。
- 更新下载按单文件显示进度，安装前验证 Pro 包名、递增版本及原签名证书。

本地离线 clean Release 验证：77 项 JVM 测试通过，Lint 0 错误、33 警告、13 信息。正式 APK 不可调试、无测试入口，仍签历史原证书，可覆盖安装，无需卸载。

两台 Android 17 设备已执行主题、字体、横竖屏、真实多指手势、多选、暂停续跑与进程恢复检查。指定三张人像在两台设备的 V6/V7/参考模式共 18 组完成；四个合成 SBS 视频完整解码，16 帧时间戳及复制音频哈希与源文件一致。测试副本及其缓存已清理，原图未修改。详细范围与验收过程中发现的边界见 [技术记录](../studio-v1.3.00.md)。
