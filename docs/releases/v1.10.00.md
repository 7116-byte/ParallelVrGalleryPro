## 真机交互与任务

仅使用已授权平板，原生 2136×3200、density 440、原字体 1.25；横屏为自然旋转后的 3200×2136，没有覆盖物理尺寸或模拟手机。手机未操作。原视频生成任务事先获用户授权备份并临时隔离，测试只用专属合成素材。

- 设置四页双向滑动、点击标签同步、生成页图片/视频双向滑动通过。视频长按只选择合成 B，开始/暂停所选及计数按真实状态变化。完成项跳过；不清理原媒体或历史结果。
- 字体 1.6、横竖屏和深色模式检查：四标签不重叠，纵向滚动后标题与标签仍可见；结束恢复原字体、主题和旋转模式。
- 排队 B 暂停前捕获参数；将当前强度从 40 改成 37 后续跑，B 仍为原 s40 参数版本。之后恢复原偏好。
- 发现并修复两次真实竞态：首次标签恢复覆盖新入队状态；暂停后晚到的模型准备回调覆盖 PAUSED。后者在冷模型准备期间暂停，再等待 20 秒，仍为用户暂停，未改回生成中。
- 合成视频 C 与 A 在后台运行，跨片期间前台服务 startForegroundCount 为 1；A 重建后最终完成 240 帧，队列结束服务退出。该耗时不是新算法性能比较，不能宣称 GPU 推理提速。
- SIGKILL 后平板系统 35 秒内没有自动重启 sticky 服务，记录为限制。显式调用同一重建准入路径后，已开始项续跑、用户暂停 B 保持暂停。不能把这项显式测试写成厂商系统自动恢复通过。
- Debug 调用系统时限的同一暂停处理入口，B 保存为 PAUSED / SYSTEM_LIMIT，服务停止；没有等待六小时或验证所有厂商的真实时限行为。
- 正式签名 Release 从仅含一张合成图片的专属相册进入 Viewer，退桌面后完成 770 模型、强制 GPU 生成，图片队列归零；没有扩到私人来源。暂停通知改为“已暂停”且可划走。

界面测试与本次原生生成均为本轮实测；历史画质、长视频、音画同步、手机及完整手势矩阵没有在本版全部重跑，不引用旧结果冒充新验收。
