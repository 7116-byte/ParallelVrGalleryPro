# v1.16.00 · Rust 原生核心、模块化重构与液态玻璃自适应 UI

本版本从 v1.15.02 出发完成三阶段架构升级：全部核心深度与立体渲染管线统一迁移至单一源码 Rust 原生库、拆分原 `MainActivity.kt` 单文件巨石，并将 Jetpack Compose 界面升级为兼容手机与平板的液态玻璃自适应设计，同时保持原有全部功能、缓存路径、包名与签名兼容。

## 1. 单一源码 Rust 原生核心（`pvg-core` + `pvg-jni`）

- 将六种立体投影模式（含 ComfyUI Legacy/Subpixel、Reference V8/V9、Legacy/Centered）、深度归一化与方向映射、高斯与盒式滤波、多插值深度缩放、时序平滑、QNN/TFLite 张量打包与读取、视频时间轴分段校验及缓存原子发布统一收口至 Rust 并行核心，通过 JNI 编译为 `libpvg_core.so`（Android 四架构：arm64-v8a / armeabi-v7a / x86 / x86_64，API 30，16 KB 页对齐，30 个导出符号）及桌面 Host JNI 库。
- 原图与缓存格式、参数版本键和签名完全兼容，可直接从旧版覆盖升级。

## 2. 应用层模块化拆分

- 将原超过一万行的 `MainActivity.kt` 按职责拆分为 11 个独立模块（`GalleryModels`、`GalleryStores`、`GalleryViewModel`、`VrPipeline`、`MediaIoUtils`、`StudioAppShell`、`StudioGeneratedScreen`、`StudioSettingsScreen`、`StudioDebugScreen`、`StudioViewerScreen`、`StereoZoomMath` 等），显著提升可维护性与测试隔离度。

## 3. 液态玻璃自适应 UI 与交互修复

- **实时 GPU 背景毛玻璃**：新增 `StudioBackdrop` 实时渲染层，在 Android 12+ 使用硬件 `RenderEffect` 呈现顶部渐进半透明毛玻璃遮罩、右上角圆形玻璃按钮、同窗口毛玻璃二级弹窗与底部双层液态玻璃 Dock（外层磨砂大胶囊 + 内层更通透光学滑块，支持点按与横向拖切）。
- **顶部双圆按钮去重与真实排序/视图/筛选**：第一按钮专注排序（按拍摄时间 / 按添加时间，读取 MediaStore `DATE_TAKEN` / `DATE_ADDED` 并持久化）、视图（按日期分组 / 平铺网格 / 大图·标准·紧凑列数）与筛选（全部媒体 / 仅照片 / 仅视频 / 已生成 VR / 未生成 VR）；第二按钮统一收口任务与进度、刷新媒体库、使用指南与唯一顶层设置入口。
- **侧边独立回顶与双端自适应**：底部 Dock 仅保留居中导航切换；「回到顶部」独立位于右侧边栏并优化深滑一键瞬时归顶；平板横屏（≥ 840 dp）启用双栏相册与双栏设置分屏，手机紧凑屏（< 600 dp）自动切换单栏与紧凑菜单宽度。
- **修复详情页跨中轴线双指缩放反转**：重构 `StereoPinchSession` 数学模型（静态图与 SBS 视频共用），改用双指真实屏幕距离计算倍率、手势期内锁定中点所属眼别并联动双指平移，根除跨 1/2~3/4 中轴线时往外拉缩小/往里推放大的倒挂问题。
