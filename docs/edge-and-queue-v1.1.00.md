# v1.1.00: 边缘模式、来源队列与删除一致性

## 边缘变化的代码依据

比对 v1.0.06 与 v1.0.07：上一版将旧平滑函数改为居中均值滤波。旧算法只累积当前及先前像素，却按居中窗口长度归一化，因此除了边界形态，还改变了深度幅度。

在均匀深度值 1、直径 3 的内部区域，旧版输出约 4/9，新版输出 1；直径 5 时旧版约 9/25，新版仍为 1。使用相同强度时，视差不再等价。这是代码可复现的行为回归，但不能仅凭截图确认所有轮廓异常都由它造成。

新增 `DepthEdgeMode`：

- `LEGACY_V6`：逐项恢复 v1.0.06 平滑计算，包括非标准归一化。默认选项。
- `CENTERED_V7`：保留 v1.0.07 的居中均值滤波。
- 图片和视频均从同一参数传入平滑函数。分别沿用 `depthV6` / `depthV7` 缓存标识，其余格式、眼序和水平填充不变。
- 视频持久队列追加模式字段；旧队列从已存缓存版本识别模式，避免续跑时混用深度处理。
- 切换不会自动重算已有成品或改变已经入队任务的参数快照。对同一张原图分别明确生成，才可比较两种结果。

## 原参考项目

旧项目 README 指向 [SamSeenX/ComfyUI_SSStereoscope](https://github.com/SamSeenX/ComfyUI_SSStereoscope)。本次核查了 [sbs_v2.py](https://github.com/SamSeenX/ComfyUI_SSStereoscope/blob/main/sbs_v2.py)、[depth_estimator.py](https://github.com/SamSeenX/ComfyUI_SSStereoscope/blob/main/depth_estimator.py) 和 [外部深度节点](https://github.com/SamSeenX/ComfyUI_SSStereoscope/blob/main/sbs_v2_with_external_depth.py)。

原水平投影使用整数位移、方向填充。其新版外部深度节点另有空洞掩码与 OpenCV Telea 修补，并采用不同的位移尺度等约定，不可视为手机现有算法的直接替代。本版未引入 OpenCV/Telea，避免再次改变眼序、强度或性能；开关仅控制手机实际发布过的两种平滑行为。

## 队列约束

1. 只有实际打开的普通图片 Viewer、有效 ALL/ALBUM 来源范围、开启 VR，才允许生成新的邻图任务。
2. 当前图片使用独立高优先级入口；推理拥有者线程接收当前图片后才开放邻图流水线。当前图已缓存时可直接开放。
3. 切换图片暂停尚未开始的旧窗口任务，运行中的单张不硬中断；新窗口可重新接纳自动暂停项。
4. 来源切换暂停与窗口暂停分别标记。全局来源恢复只恢复来源暂停项，不能把旧窗口、历史暂停或失败项全部复活。
5. 生成页、生成页 Viewer 和退出 Viewer 后禁止扩展预加载。原 `regenerateImages` 打开普通 `vrMode`、后台回退到首页锚点扩队列的路径已移除。
6. 退出普通 Viewer 后，已接纳任务可完成，但不继续扩窗。进入生成页可恢复已有来源暂停任务，因此管理网格仍可能因这些任务完成而增加成品；这不等于新建邻图任务。
7. 生成 Viewer 使用进入时的 key 列表，后台成品不会追加到这次左右浏览范围；空范围和已删除范围不会回退到全部媒体。
8. 日志分别记录 `new-prefetch`、`resume-window`、`resume-source`、`manual`，并附来源/相册。仅解码已有缓存的 Viewer 预读不属于 VR 生成。

## 删除与发布缓存

- `GenerationGuard` 给任务分配修订 token，删除时同步失效。任务领取、来源切换、失效检查和发布使用同一锁序。
- 新成品先写入缓存扫描范围外的独立 `image_work` 目录，完整后才移动到成品目录并登记索引。失效任务不能提交文件、READY 或进度。
- 删除整库时也取消已持久化但尚未载入图片列表的任务；删除版本时涵盖刚被 worker 领取但尚未开始的任务。
- 自动预加载抑制按图片 key 持久化。重新打开该原图或明确重新生成可解除，但不会重新认可旧 token。
- 文件删除失败明确报错；临时工作目录在正常异常/取消路径清理。进程被系统强杀后的临时目录清理不在本版保证范围。

## 验证

本地执行 `testDebugUnitTest lintDebug assembleDebug`。34 项 JVM 测试通过，0 失败；Lint 0 错误、46 警告。包括旧/新滤波精确路由、旧滤波独立参考计算、参数与缓存模式隔离、生成 Viewer 列表不增长、禁止生成页/视频/关闭 Viewer 预加载、删除与发布竞争、删除抑制持久化、当前图先启动等。

未连接 Android 真机，以下仍需实测，不宣称已通过：

- 同一张边缘明显的原图，在相同强度下分别生成 depthV6 / depthV7；对比轮廓和立体强度。
- 从全部或相册打开当前未生成图，确认当前图先开始，邻图只来自该来源列表。
- 切到生成页后查看日志，允许 `resume-source` 和已有任务完成，不应新增 `new-prefetch`；详情左右滑范围不因完成任务而扩大。
- 生成进行中删除全部版本，等待旧推理结束、刷新、重启，已删项不应回来。
- 相册首页长按、拖动、取消、勾选多个版本后确认删除；系统原图仍在。
- GPU 强制模式、视频暂停/续跑、单播放器 SBS、双眼同步缩放与原来一致。
