# ParallelVrGallery Pro

一个本地 Android 图库应用：按“全部 / 相册 / 生成”浏览系统图片和视频，并在手机本地生成平行眼 SBS VR 缓存。

## v1.1.01 更新

- 移除 v1.1.00 的全局删除预加载黑名单，修复删除缓存后只生成当前图、邻图不再预加载的问题。删除仍使旧任务失效，不能把旧结果写回来；以后从全部页或相册重新浏览时可正常生成。
- 生成页及其 Viewer 不新增普通预加载，只继续已有任务或恢复来源切换暂停的任务；手动“重新生成”仍是明确请求。退出普通 Viewer 也不继续扩窗。
- 启动时后台初始化已下载的当前图片模型，校验模型、创建解释器/GPU delegate 并分配张量，供首张图复用。不自动下载、不生成测试图片，不改 GPU 强制模式；首次实际推理仍可能有额外开销。
- 已完成的视频即使缺少内存 job 记录也显示 100%；封装未完成仍显示生成中，不再把未知帧数显示成 0/0。
- “深度平滑”改为“深度图滤波窗口”并说明：在 518×518 深度图上滤波，不是放大到原图后多次插值。旧/新滤波算法与缓存版本不变。
- 验证与限制见 [docs/prefetch-and-startup-v1.1.01.md](docs/prefetch-and-startup-v1.1.01.md)。以下 v1.1.00 的持久删除抑制说明仅记录当时行为，本版已撤销。

## v1.1.00 更新

- 设置新增“边缘处理”：默认“旧版兼容”（v1.0.06 / depthV6），可切换“新版平滑”（v1.0.07 / depthV7）。图片与视频共用，缓存版本分开，切换不自动改写成品。
- 当前图片实际进入推理后，邻图才进入原有来源限定的 2/4/8 预加载流水线；已有缓存的当前图不必等待推理。
- 生成页不新建邻图任务，只运行明确手动请求或已有的来源暂停任务。生成页 Viewer 使用进入时的范围与顺序，不再将后台新成品追加进左右浏览列表。
- 删除时先使相关任务失效，再删除文件；过期生成结果不能重新写回成品库。删除项不会因自动预加载或重启恢复而再生，明确打开该原图或重新生成可重新请求。
- 生成图片相册首页支持长按多选、拖动连续选择，点击删除后确认；不删除系统原图。
- 补充深度强度、平滑、边缘填充、分辨率、worker 与 GPU 设置说明。实现依据及验收清单见 [docs/edge-and-queue-v1.1.00.md](docs/edge-and-queue-v1.1.00.md)。

## v1.0.07 更新

- 推理会话固定线程创建、运行、释放；当前图片优先于尚未开始的后台推理，运行中的单帧不强行中断。
- 修正深度均值滤波，缓存算法版本升级到 `depthV7`；旧成品仍可浏览，不混用旧深度帧。
- 图片缓存改为内存索引增量更新，队列状态合并后原子写入；生成完成不再反复遍历整库文件。
- Viewer 解码统一去重，使用按字节计量的 LRU；邻图加载屏幕级预览，放大时再请求较高分辨率。
- 视频采用有界顺序流水线，后台缓存写入与编码分别消费同一帧；取消和异常路径释放所有在途资源。
- 视频保留原始 PTS；顺序 MediaCodec 解码先验证颜色、旋转和转换成本，不适合的设备走兼容取帧并记日志。
- SBS 视频仅在新帧、缩放或视口变化时重绘；继续使用单播放器，不改变同步缩放手势。
- 加入 JVM 回归测试和 GitHub 构建检查。工程说明与真机验收清单见 [docs/optimization-v1.0.07.md](docs/optimization-v1.0.07.md)。

## 功能

- 系统图库式首页：`全部 / 相册 / 生成` 三个入口。
- 全部页按时间浏览图片和视频；相册页按系统相册/文件夹浏览。
- 图片 VR：本地生成深度图和 SBS 平行眼图，支持缓存、调试页和调试包分享。
- 视频 VR：手动加入队列后逐帧生成 SBS 视频，并尽量保留原音频。
- 生成页：按图片/视频管理已生成、生成中、暂停和失败的缓存任务。
- 模型按需下载：APK 不内置大模型，首次生成前下载并校验 SHA-256。

## 诊断说明

如果视频调试页里显示：

```text
深度推理 360ms
SBS 39ms
缓存写入 21ms
编码提交 17ms
```

说明瓶颈主要在深度模型推理。`视频深度 worker 数 = 2` 会尝试并行跑两个独立模型会话；如果显存或内存吃紧，可以在设置里降回 1。

## 模型资产

APK 不内置 `depth_anything_v2.tflite`。首次生成 VR 前，App 会从 GitHub Release 下载模型并校验 SHA-256。

覆盖安装升级通常不会清理 App 私有外部目录，所以本地已下载过模型时不需要重新下载；卸载 App 会由系统清理该目录。

## 第三方项目与依赖

本项目是新的 Android App，没有复制旧 APK 的源码或资源。主要依赖和参考包括：

- Android SDK / Jetpack Compose / AndroidX / Material3：App 框架和 UI。
- TensorFlow Lite / TFLite GPU Delegate：本地深度模型推理。
- Depth Anything V2：当前图片/视频逐帧深度估计模型来源。
- Video Depth Anything：视频时序一致性深度模型方向，当前作为待导入移动端模型选项。
- SamSeenX/ComfyUI_SSStereoscope：SBS 生成思路参考，包括深度平滑、相对视差和边缘填充。

更详细说明见 [NOTICE.md](NOTICE.md)。
