# ParallelVrGallery Pro

一个本地 Android 图库应用：按“全部 / 相册 / 生成”浏览系统图片和视频，并在手机本地生成平行眼 SBS VR 缓存。

## v1.10.00：横滑切页与后台队列

- 设置四页、生成页图片/视频支持左右滑动；固定设置标题，参数卡片按可见范围加载，取消整页缩放过渡。
- 视频提供全部开始/暂停和多选开始/暂停，显示作用数量；续跑保留各任务参数与已有帧，不等同于重新生成。
- 前台服务覆盖整批任务，Activity 退出保留工作拥有者；暂停后的迟到回调不能把状态改回生成中。
- 增加后台状态和恢复说明。厂商清理、强停及系统时限仍有边界，不能保证进程永不被杀；实测见 [技术记录](docs/background-and-navigation-v1.10.00.md) 与 [验收记录](docs/releases/v1.10.00.md)。

## v1.9.00：从原图保存无损 PNG

- 预览继续 JPEG 100；保存副本捕获所选历史结果，从原图按其模型、模式、强度、反转和深度放大参数重新生成，直接写无损 PNG。
- 原图眼直接复用，只投影另一眼；逐行拼接写 PNG，不读取 JPEG 眼图或旧导出文件，不额外创建全幅 SBS 位图。
- 保持结果记录的实际尺寸；原图缺失/变化、参数损坏或内存不足明确失败，不降低尺寸或用缓存冒充。保存不修改旧结果、设置或来源队列。
- 视频仍保存已生成 H.264 MP4；原帧复用的实际收益与限制见 [技术记录](docs/original-png-v1.9.00.md)。

## v1.8.00：新任务推理 I/O 与兼容会话复用

- 比较未生成过的完整任务，不计入结果缓存恢复：平板 720p/48 帧新视频在同配置模型已就绪时 17.77→12.66 秒；模型完全冷启动时 18.06→17.42 秒。条件不同，不能混用提速百分比。
- RGB 分块批量写入、浮点输出批量读取；V10 使用逐像素等价的覆盖优化。原精度、模型输入、输出尺寸和码率保持。
- 新视频复用相同配置的已就绪会话；不同视频配置不淘汰图片模型。GPU 线程归属和当前图优先保持。
- 8 份图片眼图与 96 份视频眼图字节一致，48 个原始 PTS 和音频核对通过。模型就绪的新图片小样本约快 4–13%，首图建模和 GPU 算子仍是瓶颈。
- 详见 [新任务实测](docs/fresh-generation-v1.8.00.md) 与 [验收记录](docs/releases/v1.8.00.md)。

## v1.7.00：生成提速与方向预加载

- 热图片实测总耗时约减少 16–21%；完整缓存短视频恢复从 4.57 秒降到 0.40 秒。首次视频生成仍受深度推理限制，不外推为所有视频同等提速。
- 自动预加载首次前后均衡，翻页后优先连续方向并保留反向邻图；来源、2→4→8 档位和当前图优先不变。固定档仍均衡。
- 深度诊断 PNG 改为逐行灰度编码，像素与原图一致；眼图缓存继续 JPEG 100，加写缓冲，不降尺寸或质量。
- 新增明确的 PNG/AVIF 保存格式，默认 PNG 不增加现有缓存的像素损失；现有 AVIF 色彩异常会被严格校验拦截，不自动换格式。
- 实测格式表、精度边界与未解决项见 [性能记录](docs/performance-v1.7.00.md)，本次构建和设备结果见 [发布验收](docs/releases/v1.7.00.md)。

## v2.30 更新

- 视频生成新增“视频深度 worker 数”，默认 2 个独立深度模型会话，用于并行跑原始深度推理。

## 功能

- 系统图库式首页：`全部 / 相册 / 生成` 三个入口。
- 全部页按时间浏览图片和视频；相册页按系统相册/文件夹浏览。
- 图片 VR：本地生成深度图和 SBS 平行眼图，支持缓存、调试页和调试包分享。
- 视频 VR：手动加入队列后逐帧生成 SBS 视频，并尽量保留原音频。
- 生成页：按图片/视频管理已生成、生成中、暂停和失败的缓存任务。
- 模型按需下载：APK 不内置大模型，首次生成前下载并校验 SHA-256。

## 诊断说明

如果视频调试页里显示：

```text
深度推理 360ms
SBS 39ms
缓存写入 21ms
编码提交 17ms
```

说明瓶颈主要在深度模型推理。`视频深度 worker 数 = 2` 会尝试并行跑两个独立模型会话；如果显存或内存吃紧，可以在设置里降回 1。

## 模型资产

APK 不内置 `depth_anything_v2.tflite`。首次生成 VR 前，App 会从 GitHub Release 下载模型并校验 SHA-256。

覆盖安装升级通常不会清理 App 私有外部目录，所以本地已下载过模型时不需要重新下载；卸载 App 会由系统清理该目录。

## 第三方项目与依赖

本项目是新的 Android App，没有复制旧 APK 的源码或资源。主要依赖和参考包括：

- Android SDK / Jetpack Compose / AndroidX / Material3：App 框架和 UI。
- TensorFlow Lite / TFLite GPU Delegate：本地深度模型推理。
- Depth Anything V2：当前图片/视频逐帧深度估计模型来源。
- Video Depth Anything：视频时序一致性深度模型方向，当前作为待导入移动端模型选项。
- SamSeenX/ComfyUI_SSStereoscope：SBS 生成思路参考，包括深度平滑、相对视差和边缘填充。
